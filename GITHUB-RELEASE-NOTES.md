# MoonClocks 1.0.3

Compatibility update for the Pale Moon 35.0.0 milestone.

## Changes

- Updated Pale Moon compatibility from `34.*` to `35.*`.
- No runtime, visual, or timezone database changes.
- Bundled timezone database remains IANA tzdb 2026b.

## Upgrade note

MoonClocks is a separate fork and uses a different extension ID than the original FoxClocks. If migrating from the original FoxClocks or an old FoxClocks Legacy test build, back up your profile and clock settings, uninstall the older extension, restart the application, and then install MoonClocks. Existing MoonClocks users can update normally.
